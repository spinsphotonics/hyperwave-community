# Verification report: facts/WP-21.md (Fuse and relay maps)

**Method:** This WP is safety-adjacent (a transposed amperage in a fuse table can send a reader
to the wrong part, or worse, toward "just use a bigger fuse"), so per the verifier brief I did a
direct independent re-read of the source rather than only checking the card's own citations.

1. Fetched the real 2008 Fit Owner's Manual PDF myself via
   `curl -sL --max-time 25 "https://r.jina.ai/https://techinfo.honda.com/rjanisis/pubs/om/AAA080/AAA0808OM.pdf"`
   (direct `curl` to techinfo.honda.com still fails TLS handshake in this environment, consistent
   with ADAPT-2's known dead end; the r.jina.ai reader proxy worked and returned the full 282-page
   manual, confirmed titled "2008 Fit Owner's Manual" at the top of the fetched text).
2. Located the "Fuses"/"Fuse Locations" pages (printed pages 233-237) in the raw fetched text.
   The manual's own fuse-chart table came through OCR'd as jumbled runs (position numbers, then
   amperages, then circuit names, as separate blocks) rather than a laid-out table — exactly as
   WP-21.md's own header note warned.
3. Independently reconstructed the jumbled OCR position-by-position (not by trusting WP-21.md's
   reconstruction — I re-derived it myself from the raw text) and cross-checked the result against
   WP-21.md's printed tables, and separately against a fresh fetch of the WP-21-cited corroborating
   source (S-WP21-A, fuse-box.info's clean "Honda Fit GD 2007-2008" table, refetched via
   `r.jina.ai` this session, not read from WP-21.md's quotation of it).
4. Checked the prose facts (F-WP21-001 through -010, -013 through -015) against the same raw
   manual text I fetched.

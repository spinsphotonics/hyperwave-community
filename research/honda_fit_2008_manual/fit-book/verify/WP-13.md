# Verification report: facts/WP-13.md (Known weak spots and shop guidance)

**Method:** Unlike the original research pass (which used WebSearch snippets only, per its own
stated ADAPT-1 rationale), this verification pass **directly re-fetched nearly every cited URL**
with curl (browser User-Agent) or, where curl returned a bot-challenge/403 (RepairPal), the
r.jina.ai reader proxy — both worked for essentially every Tier 3 site in this file (RepairPal,
YourMechanic, oards.com, thepricer.org, autobodyshopnear.com, carsymp.com, AAA, Kwik Kar Spring
Valley). The claimed value was checked against the actual page text pulled today, word for
word where a specific number or quote was claimed.

     Fit-specific estimate in this rough bracket) is still true and directly re-confirmed today.

     filed under the **2nd-generation (GE8) sub-forum**, with no second GD3-specific source
     confirming the same pricing — a real, if minor, D8 generation-mixing risk that the original
     card disclosed but did not fully resolve. Downgraded from medium to low confidence.

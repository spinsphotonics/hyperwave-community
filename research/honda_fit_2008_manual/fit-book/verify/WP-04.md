### FAIL found and corrected

- **F-WP04-009** claimed the "Instrument Panel Indicators" section (pages 60-66) lists **24**
  named indicators, of which **5** don't apply to base trim. Recounting directly from the
  re-fetched manual text — both the page-59 overview diagram's callouts and each dedicated
  indicator subsection heading on pages 60-66 — the real count is **26** named indicator topics
  (25 shown as callouts in the page-59 diagram, plus "Turn Signal and Hazard Warning Indicators,"
  which has its own subsection heading on p.63 but is not a separate callout in that particular
  diagram). This also matches the fact card's *own* itemized indicator list two lines below,
  which names 26 items when counted, and matches F-WP04-032's own explicit 6-item exclusion list
  (Fog Light, Security System, Cruise Main, Cruise Control, DRL, Washer Level) elsewhere in the
  same file — so "5 do not apply" was also wrong; it should be 6. 26 − 6 = 20, which matches the
  warning-light table's own row count exactly, so the correction is now internally consistent
  with the rest of the file. **Fixed directly in `facts/WP-04.md`** (F-WP04-009's Value field
  rewritten to state 26/6/20, with a note explaining the correction) rather than merely marking
  it UNVERIFIED, since the correct value was directly recoverable from the same Tier 1 primary
  source — matching the correction-pass pattern already used on WP-01/WP-02.

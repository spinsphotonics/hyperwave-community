### The year-sourcing issue (read this before trusting a blanket "YEAR-OK")

I independently grepped the full re-fetched S-HONDA-OM2007 text for "2007-2008," "first
generation," and "GD3" — **none of those phrases appear anywhere in the document.** The bare
string "2007" appears only 4 times, on the cover/copyright pages. Taken completely literally,
Section 6 rule 3 of the plan ("Confirm the source names 2008, 2007-2008, first generation, or
GD3") is **not** satisfied by this source alone.

However, I did not mark these YEAR-FAIL, for a reason the card itself already argues and I
independently confirm: D2 defines this book's vehicle as "chassis code GD3, sold in the US for
model years 2007-2008 only." A source that says "2007 Honda Fit" is unambiguously about the
*same* GD3-generation car this book covers — it is not the kind of year confusion D8 exists to
catch (a different-generation 2009-2014 GE8 source). It is one model year short of "2008,"
within a generation the plan itself treats as a single two-year unit. I therefore marked these
**"YEAR-OK*"** (asterisk = qualified) rather than YEAR-FAIL, and flag this explicitly so a human
reviewer can override the call if they read D8 more strictly than I did. Facts that are also
corroborated by S-HONDA-FEATURES or S-HONDA-OVERVIEW — both explicitly, unambiguously dated/titled
for the 2008 model year — get a clean, unqualified **YEAR-OK**.

If a future reviewer decides YEAR-OK* should actually be YEAR-FAIL, the fix is not to discard
these facts — it is to note that no separate source contradicts any of them, D2 already scopes
"2007-2008" as one generation, and the WP-05 file itself already states (accurately, I confirmed)
that no equipment change was found between the two model years for any control covered here. The
substance of every one of these facts is value-verified; only the literal year-phrase test is in
tension with the plan's own two-year vehicle scope.

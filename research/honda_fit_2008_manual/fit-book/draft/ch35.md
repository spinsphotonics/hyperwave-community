# Chapter 35: The Check Engine Light and OBD-II Codes

## The short version
The check engine light, formally called the Malfunction Indicator Lamp (MIL), warns you that a system tied to emissions or engine control has a problem. OBD-II, short for On-Board Diagnostics, second generation, is the standard system every 1996-and-newer US gasoline car uses to store a trouble code describing that problem. A code reader plugged into the port under your dashboard shows you the code, and this chapter's table shows you what 20 common codes mean and where to start checking.

## The full explanation

### What OBD-II is, and what the check engine light means

OBD-II is a federal standard. Every gasoline car sold in the US since 1996 must have it, including your 2008 Fit.<!-- F-WP12-001 --> The system constantly watches the engine and emissions parts. When something goes outside its normal range, the car's computer, called the ECM (engine control module), saves a code describing the problem and turns on the check engine light.<!-- F-WP12-001 -->

Each stored code is called a DTC, short for Diagnostic Trouble Code. A DTC does not always mean a part is broken. It means the ECM saw a reading it does not expect, which could point to a broken part, a loose connector, a low fluid level, or something else entirely.<!-- F-WP12-002 --> That is why this chapter's table always lists a first thing to check, not just a part to replace.

### Where the OBD-II port is

The OBD-II port, also called the data link connector (DLC), is a 16-pin plug you connect a code reader to. On your 2008 Fit, it sits under the dashboard on the driver's side, at or a little above the brake and gas pedals, close to the steering column.<!-- F-WP12-001 --> It usually has no label, and it may sit tucked up against the underside of the dash instead of hanging down in plain view. You will likely need to crouch down and feel for it with your hand, or put your head down near the pedals to see it.<!-- F-WP12-001 -->

This location is not random. A federal standard called SAE J1962 sets the rules. The port must sit between the driver's end of the dashboard and a point just past the center of the car. It must mount to the dashboard structure and be reachable from the driver's seat without tools.<!-- F-WP12-001 --> That rule is why "under the dash, driver's side, near the steering column" is the right first place to look on almost any 1996-or-newer US car. A source naming the Fit by name confirms this location specifically for your car.<!-- F-WP12-001 -->

### Reading and clearing a code, in general terms

A code reader, sometimes called a scan tool, plugs into the OBD-II port. With the ignition turned on, it shows you any stored DTCs as a letter-and-number code, such as P0300. You then look up what that code means, which this chapter's table does for the 20 most common codes on this car.

Clearing a code turns off the check engine light, but it does not fix the problem that caused the code. If the underlying cause is still there, the code, and the light, will likely come back. This book could not confirm the exact menu steps for every code reader model, since readers vary by brand. Follow the instructions that come with your own reader.

### Should you keep driving with the light on?

This depends on how the light behaves. A steady check engine light means a problem exists, but usually is not an emergency by itself. A flashing check engine light is more serious. It means an active, severe misfire, a condition where a cylinder is not firing correctly, which can send unburned fuel into the hot catalytic converter and destroy it.<!-- F-WP12-002 --> If your check engine light is flashing, pull over and stop driving. Do not continue on to your destination first.<!-- F-WP12-002 -->

### The 20 codes this book found for the 2008 Fit

Every code below was checked against real reports from owners of 2007-2008 Honda Fits, not a generic list of what any car's computer can report.<!-- WP-12 Section B intro --> Most are backed by two independent owner reports describing this exact code on this exact generation of car. Two codes have only one such report each, and this book flags them honestly rather than presenting them as more certain than they are.

**Key to the Source column:**
- **TSB** — Backed by an actual Honda Technical Service Bulletin, the strongest evidence in this list.
- **2+** — Backed by two or more independent 2007-2008 Fit owner reports.
- **1 only** — Backed by only one 2007-2008 Fit owner report found. Treat this as a lead, not a confirmed pattern.

### Being honest about the "1 only" codes

This book's research found only one 2007-2008 Fit-specific report for P0451 and for P0113, not the two independent reports found for every other code in this table.<!-- F-WP12-019 --><!-- F-WP12-021 --> Both are still real, specific reports about this exact generation of car, not invented entries. But treat them as a lead worth checking, not a settled pattern the way the other 18 codes are.<!-- F-WP12-019 --><!-- F-WP12-021 -->

## What can go wrong
- **Assuming a code always means a broken part.** A DTC often points to a wiring problem, a loose connector, or a low fluid level instead. Always start with the "first thing to check" column, not a parts order.<!-- F-WP12-002 -->
- **Ignoring a flashing check engine light.** A flashing light means stop driving, not "get to it this week."<!-- F-WP12-002 -->
- **Clearing a code and assuming the problem is fixed.** Clearing only turns off the light. If the cause is still there, the code will likely return.
- **Treating P0451 or P0113 as a fully confirmed pattern.** Both only have one Fit-specific report behind them in this book's research.<!-- F-WP12-019 --><!-- F-WP12-021 -->
- **Skipping the cheap check for P2646 or P2647.** Honda's own bulletin says checking the oil level and condition comes before replacing the switch.<!-- F-WP12-010 --><!-- F-WP12-011 -->

Vehicle: 2008 Honda Fit, US market, base trim, first generation, chassis code GD3.
Rule D8 applied throughout: every source below was checked for "2008", "2007-2008",
"first generation", or "GD3" language, or is a government API query that returns those
fields directly (NHTSA vPIC, NHTSA SafetyRatings). Where a source could not be pinned to
this generation, or where sources disagree, both are recorded and the conflict is flagged.

Base Fit LACKS (i.e., these are Fit Sport-only): steering wheel-mounted paddle shifters (on automatic transmission models only), full-body aero kit/underbody aero kit, rear roofline spoiler, fog lights, keyless remote entry with security system, cruise control, 15-inch aluminum-alloy wheels (base has 14-inch steel wheels with full covers), premium 200-Watt 6-speaker audio system with MP3/WMA playback, 5-mode equalizer, and auxiliary audio jack (base has a 4-speaker AM/FM/CD system).
Base Fit HAS (standard, same as Sport): air conditioning, power windows, power door locks, power mirrors, and the 60/40 split "Magic Seat" rear seat system (all seating/cargo modes). Base tires are P175/65R14 81S vs Sport's P195/55R15 84H.

# WP-10 Fact Cards — Torque specs and fitment numbers (Appendices C, E)

Vehicle: 2008 Honda Fit, US market, base trim, first generation, chassis code GD3.

**Honesty note for this WP (per RESEARCH_PLAN.md and queue/decisions_needed.md ADAPT-1/2):**
The factory service manual (Helm, S-002) and Haynes 42030 (S-003) are both paywalled/print-only
with no free full-text equivalent found — confirmed again this pass, no new access route found.
Per the WP-10 task brief, this WP therefore leans on cross-referenced enthusiast/parts sites and
forum posts for most torque values, and on a direct read of the official owner's manual (Tier 1)
for the values it actually publishes (lug nut torque, oil drain plug torque, tire pressures, tire/
wheel size). This WP's average confidence is honestly lower than WP-01/WP-03/WP-04, as expected.
Several values are left UNVERIFIED rather than guessed — see the notes on each card.

**Good news this pass:** the exact cold tire pressure PSI numbers that WP-01/WP-03 flagged as
image-only on hfitinfo.com were found in the actual 2008 Fit Owner's Manual PDF text (S-023,
techinfo.honda.com, read in full via the r.jina.ai proxy) — see F-WP10-010.

**Source-ID naming note:** this project's `sources/` directory is shared by multiple concurrent
work-package passes, and plain numeric IDs (S-0##) have already collided at least twice this
session (see the recovery note in facts/WP-21.md and queue/blocked.md). Every NEW source this WP
found is therefore filed under `sources/S-WP10-<letter>.md` instead of the next unclaimed number,
to avoid re-colliding with concurrent work. This pass discovered, after drafting, that the plain
numbers first chosen (S-028 through S-038) were already claimed by other work packages (WP-08,
WP-09/WP-13, WP-11, WP-21) — those numeric files have been restored to their rightful original
content, and this WP's own cards were moved to the S-WP10-* names below. See queue/blocked.md for
the full incident note.

Chapter: 49 (Appendix E)
Question: Largest tire size the community commonly runs without rubbing on stock/lightly modified suspension
Value: Community consensus (two independent Tier 4 sources) is that 195/50R15 (on a 15x6.5 or 15x7 wheel, +40 to +42mm offset) is a commonly-reported "fits without rubbing" size at stock ride height. A narrower 195/45R16 was suggested by one source as a safer 16-inch alternative.

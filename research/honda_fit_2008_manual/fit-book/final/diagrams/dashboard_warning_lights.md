# Dashboard Warning Lights — Reference Sheet

**Caption:** A plain-language reference sheet for all 26 instrument-panel indicators described in the 2008 Fit owner's manual, showing which 20 actually appear on a US base-trim dash — for Chapter 7 (The Dashboard Explained).

## Why this is a reference sheet, not a picture of the dashboard

This book has no image-generation tool and no photo of a real 2008 Fit instrument
cluster. Drawing 26 accurate Honda icon glyphs from scratch — the exact line weight,
proportions, and symbol shape Honda actually used — is not something that can be done
honestly without tracing a real source, which Rule D7 forbids. Trying anyway would
produce icons that *look* plausible but are not what your dashboard actually shows,
which is worse than not drawing them at all.

Instead, each row below uses a **generic placeholder shape** (a circle, square, or
triangle) that stands in for "there is an icon here," followed by the icon's shape
**described in words**, taken directly from the owner's manual. If you want to know
what a light actually looks like, look at your own dashboard or the printed manual —
this sheet's job is to tell you what each light **means** and what to **do** about it,
which is the part a 16-year-old new driver actually needs in a hurry.

Every row traces to a Fact ID in `facts/WP-04.md`. Rows are grouped and ordered the same
way the owner's manual presents them (pages 60–66, 230–232), not by how serious they are
— see the "Safe to keep driving?" column for that.

## Part B — 6 lights described in the manual that are NOT on a US base-trim Fit

These exist in the same owner's manual (it also covers the Sport trim and Canadian
models), so they are listed here **so the book can correctly tell a base-trim owner
they will never see these** — not because a base Fit has them.

| # | Light name | Why it's not on your car | Fact ID |
|---|---|---|---|
| 23 | Fog Light Indicator | Sport-model only — the US base Fit has no fog lights | F-WP04-032 |
| 24 | Security System Indicator | Sport-model only — the US base Fit has no remote keyless entry/security system | F-WP04-032 |
| 25 | Cruise Main Indicator | Sport model and Canadian LX only — the US base Fit has no cruise control | F-WP04-032 |
| 26a | Cruise Control Indicator | Sport model and Canadian LX only — the US base Fit has no cruise control | F-WP04-032 |
| 26b | Daytime Running Lights Indicator | Canadian models only | F-WP04-032 |
| 26c | Washer Level Indicator | Canadian models only | F-WP04-032 |

*(The owner's manual's own count works out to 26 named indicators across every
US/Canada, base/Sport combination — Fact F-WP04-009 — of which 20 apply to a US
base-trim car and 6 do not, listed above as items 23–26c.)*

**If your base-trim car shows one of these six, something aftermarket or non-stock is
likely involved — Fact F-WP04-032.**

## Color note (read this before assuming a light is "red")

The owner's manual only explicitly labels **one** indicator's color in its text: the
Brake System Indicator ("(Red)"). For the Low Oil Pressure and Charging System
indicators, "commonly described as red" is a widely reported convention but is **not**
independently confirmed for the 2008 Fit specifically in this research pass — treat
those two as "usually red" rather than a confirmed fact. The Malfunction Indicator Lamp
("check engine" light) is not labeled a color in the manual at all, and the standard
amber/yellow convention was not independently confirmed for this exact car. (Facts
F-WP07-018 through F-WP07-022.)

Hyperwave Community
===================

Python SDK for GPU-accelerated FDTD photonics simulation and inverse design
via cloud API.

Hyperwave Community provides a high-level interface for building, running, and
analyzing electromagnetic simulations on cloud GPUs. Define photonic structures,
run topology optimization with adjoint gradients, and export fabrication-ready
GDS layouts, all from Python.
